CSS architecture

Stylesheet Purpose
styles.css?v=2 Main site styles -- grid system, typography, buttons, forms, layout, responsive. ~3000+ rules. Bootstrap-inspired class naming (.ic-col-*, .ic-btn-*, .ic-form-control) but custom implementation with ic- prefix
homepage.css?ver=v2 Homepage-specific: carousel, feature tiles, banner overlays
icreate.css CMS content editor classes (mostly empty placeholder selectors)
print.css Print styles
Various module CSS Contact, news, video playlist, feedback, search overlay

Notable: No CSS custom properties (variables) are used. All values are hardcoded. No CSS preprocessor output patterns detected (no source maps). The grid system is a custom 12-column float-based grid with -ms-flexbox prefixes, indicating IE11 support targets. No CSS nesting, no @layer, no modern CSS features.

2d. Breakpoints and grid

Breakpoint Width Container max-width Column prefix
Extra small (mobile) < 768px 100% .ic-col-xs-*
Small (tablet) ≥ 768px 750px .ic-col-sm-*
Medium (desktop) ≥ 992px 970px .ic-col-md-*
Large (wide) ≥ 1200px 1170px .ic-col-lg-*
XL (custom) ≥ 1400px 1400px (container-fluid max) --

Grid system: Custom 12-column float-based grid (not Bootstrap itself, but identically structured with ic- prefix). Uses negative margins on rows (-15px) and 15px column padding. Progressively adds flexbox with -ms-flexbox vendor prefix for IE11.

Fixed header: At ≥ 991px, the header becomes position: fixed with z-index: 1000. Body content is offset accordingly. Below 991px, the header is static.

Content width: The side nav is ~265px (float: left). Main content fills the remaining space. At ≥ 991px, content max-width is constrained to 60% within the carousel section. The outer container (.ic-container-fluid) caps at 1400px.

Mobile: Below 768px, the side nav collapses behind a "More" toggle button. Content becomes full-width. The fixed header becomes static.

6n. Social media links

Two sets: header (Facebook, Instagram) and footer (Facebook, Instagram, Bluesky, Parenting in Ottawa, Health Equity). Rendered as image links with icon graphics. The iCreate Social Media plugin (v4.1.2) manages the follow/share widgets.

6o. Google Translate widget

Google Translate integration with customization ID. Renders as a <select> dropdown with 200+ languages. Located in the footer area (though floated near the header visually). Uses the translate.google.com API.

6p. Feedback tab

A fixed-position "Feedback" tab on the right edge of the viewport. Links to /en/public-health-services/complaints-and-feedback.aspx. Managed by the iCreate Feedback Form plugin (v2.6.0). Rotated 90 degrees to read vertically.
