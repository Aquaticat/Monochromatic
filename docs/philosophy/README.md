# Philosophy

This document outlines the core philosophy and decision-making principles that guide the Monochromatic project.

## Organization

The philosophy is organized into focused documents:

- **[Portability and Core Principles](portability.md)**: Foundational principles around portability, interoperability, and detachable solutions
- **[Build and Execution](build-execution.md)**: Technical decisions about build systems and script execution
- **[Tool Choices](tool-choices.md)**: Rationale for HTTP framework, editor, linting, testing, bundler, and AI SDK selections
- **[Browser Support](browser-support.md)**: Future considerations for browser feature adoption
- **[CSS](css.md)**: h-css hyperscript pattern, Shadow DOM style injection, and why alternatives don't fit

Each document provides the reasoning behind specific technical decisions and architectural choices.
