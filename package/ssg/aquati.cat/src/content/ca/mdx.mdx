
Aquesta sortida HTML està manllevada de [MDN: Adding Captions and Subtitles to Video](https://developer.mozilla.org/en-US/docs/Web/Media/Audio_and_video_delivery/Adding_captions_and_subtitles_to_HTML5_video).

```html
<video controls preload='metadata'>
  <source src='sample-video.mkv' />
  <track
    src='sample-video.vtt'
    default />
</video>
```

```mdx
![sample-audio.vtt](sample-audio.opus)
```

Aquí fem servir `<video>` en lloc de `<audio>` perquè `<audio>` no admet webvtt.

```html
<video controls preload='metadata'>
  <source src='sample-audio.opus' />
  <track
    src='sample-audio.vtt'
    default />
</video>
```
