Threshold controls

Classifier result

  • Namespaced descriptions need a tail of at least 3 words.
  • Short non-namespaced descriptions need structural specificity such as uppercase, a digit, dot, underscore, or a long no-vowel token.
  • Repeated meaningful words fail, except for non-identical cause and effect phrases split by because.
  • All-uppercase phrases fail because capitalization alone is not specificity.
  • Bare camelCase identifiers with three or more words fail because they read as code names, not descriptions.
  • Compression is not run globally. Current data reaches zero errors without invoking it.
