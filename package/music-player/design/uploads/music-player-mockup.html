Deck alignment

  • Three columns with shared edges. Prev/play/next sit centred directly above the progress bar in the same column. Volume is right-aligned over the mode control, so both end on the same edge. Now playing occupies the left column across both rows.
  • Tick "alignment guides" to see the column boundaries.
  • The breakpoint moved from 800 to 1000px, because the four-segment mode control needs about 320px and below 1000 there isn't enough left for three columns without crushing the title.
  • Narrow keeps the same discipline: the progress bar's left edge lines up with the transport, its right edge with the volume.
  • No album art. The now-playing block is two text lines: title, then a play/pause glyph and the folder the track came from. The play button toggles, so the glyph and the button always agree.

Folder picker

  • Full-width panel rather than a permanent pane. Both the folder grid and the track list get the whole window, and the same interaction works at every width.
  • Open folder and Settings are in the overflow menu on the library bar, next to what they act on, not in the window-manager's title bar.

Titles

  • Tick "raw filenames" to compare. The title is the filename minus the longest prefix common to every file in the folder.
  • Splitting on the first " - " would turn Dokuhebi - Venomous Snake into Venomous Snake. Stripping the folder name would also fail: the folder is Camellia, the prefix is かめりあ(Camellia).
  • Guards: at least two files, the prefix must end at a separator, and every remainder must be non-empty. Tags first; this is the fallback.

Assumptions

  • A folder is a subdirectory of whatever you opened, so nothing calls it an artist and the mode reads "Shuffle folder".
  • Durations are invented. Folder and file names come from your screenshots.
