What I found in the existing composition

  1. Deck centering: start-only gesture padding leaves 46dp at the physical edge and 16dp at the fold, moving every playback element 15dp toward the fold.
  2. Seek consistency: 1:06 divided by 4:35 is 24%, so the existing slider position and labels disagree.
  3. Large text: the settled mode selector remains one segmented control, arranged as four connected vertical segments with full labels at 200% text.
  4. Action hierarchy: Previous and Next are separate icon buttons. Their emphasis can change without altering the settled segmented mode control beneath them.
  5. Vertical economy: gaps between the same four groups affect both deck rhythm and the folder space left above it.
  6. Hard boundary: every candidate contains exactly the accepted screen's visible elements. No feature, control, or product section is added.
