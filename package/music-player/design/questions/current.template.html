Choose unfolded TalkBack behavior

The accepted 3B screen remains visually unchanged. This review decides how TalkBack traverses its three major areas and how the current track is announced. It does not authorize production implementation.

What the installed screen reader found

Traversal defect

Default geometry interleaves panes

TalkBack visits header actions, the letter rail, track rows, folder names, then the deck. The order does not preserve either pane or one complete task.

Adaptive-group defect

Only the one-row mode group is unified

The accepted 2×2 state becomes two two-item lists. Four vertical rows lose one shared list announcement.

Current-row defect

The title is spoken twice

The baseline says “Selected. Current track: Another Xronixle. Another Xronixle. 4:35 · −1.2 dBTP. Button.”

Fixed requirements, not choices

Each adaptive arrangement now exposes one four-item radio list in accepted option order. TalkBack says “1 of 4” through “4 of 4” at one row, 2×2, and four rows. The visible screen keeps the accepted 12dp padding floor.

Decision one: major-area traversal

Every candidate keeps the same accepted pixels. Only accessibility grouping changes.

F1 · recommended

Pane by pane

  1. Folder area
  2. Playback deck
  3. Track pane
Pros
  • Follows the left pane from top to bottom, then the right pane.
  • Keeps each visual region contiguous.
Cons
  • Track rows wait until every folder target and deck control.
F2

Browse first

  1. Folder area
  2. Track pane
  3. Playback deck
Pros
  • Folder selection is followed immediately by its track results.
  • Supports the screen's browsing task.
Cons
  • Returns from the right pane to the lower-left deck at the end.
F3

Playback first

  1. Playback deck
  2. Track pane
  3. Folder area
Pros
  • Seek, transport, and mode actions arrive first.
  • Fastest path for an already-playing session.
Cons
  • Starts at the visual bottom of the left pane.
  • Moves Open and all browsing targets to the end.

Ranking: F1 > F2 > F3. F1 beats F2 because spatial containment is more predictable than crossing panes and returning. F2 beats F3 because this screen's primary structure begins with choosing folders and tracks, not controls at the visual bottom.

Decision two: current-track speech

Both options remove the baseline's repeated title. They differ in whether TalkBack receives structured state plus visible text or one hand-composed sentence.

S1 · recommended

Structured state

TalkBack: “Current track. Another Xronixle. 4:35 · −1.2 dBTP. Button.”

Pros
  • Keeps state, title, and metadata as separate semantics.
  • Visible text remains the source of spoken content.
Cons
  • Does not also say the generic word “Selected.”
S2

Composed sentence

TalkBack: “Selected. Current track: Another Xronixle, 4:35, −1.2 dBTP. Button.”

Pros
  • Explicitly says “Selected.”
  • Controls the complete spoken order.
Cons
  • Duplicates visible strings in a second assembled label.
  • Metadata or translation changes can drift.

Ranking: S1 > S2. S1 beats S2 because it removes repetition without creating a second manually synchronized rendering of the same title and metadata.
