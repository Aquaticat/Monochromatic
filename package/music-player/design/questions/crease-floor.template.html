Choose a physical-unit policy

P10 · 10mm independent minimum (Recommended)

Pros

  • Requires at least 2.5mm of combined clearance beyond this device's approximate 7.5mm crease.
  • Sets a stable physical total-separation floor if a later device has a narrower crease.

Cons

  • The measured 11.35mm box proxy is not ink or a same-height opposing pair; compliance remains unverified.
  • Could require a different layout in unmeasured states or devices.

My read: Recommend an explicit 2.5mm combined cushion beyond this crease as a policy, without claiming a demonstrated readability benefit or fit. This 10mm separation target is not the superseded 10mm estimate of the crease itself.

P0 · No independent floor, crease width alone

Pros

  • The current target's effective threshold stays at its approximately 7.5mm physical crease width.
  • Does not impose an invented global floor beyond the already accepted meaning-off-crease rule.

Cons

  • A future narrower crease would lower the effective total-separation threshold.
  • There is no independent buffer for opposing information across the fold.

My read: Sound if E2 should track only the actual obstruction, rather than promise a separate baseline. Numerically this option sets min_padding = 0mm in E2, not a new component padding value.

P12 · 12mm independent minimum

Pros

  • Requires at least 4.5mm of combined clearance beyond this device's approximate crease.
  • Provides a stricter target if stronger visual separation is worth possible layout responses.

Cons

  • The 11.35mm projected box-gap proxy cannot establish this floor's fit or failure for painted marks.
  • A state that fails this stricter target would require a visible response; none has been built or validated.

My read: Choose if the stricter physical floor is intentional even though current-state fit is unproven; do not infer automatic truncation or layout changes from the proxy alone.

Ranking: P10 > P12 > P0. I prefer P10 to P12 because a 2.5mm combined cushion is an explicit buffer and there is no demonstrated readability gain from adding the further 2mm. I prefer P12 to P0 because a cross-device independent floor is more protective than leaving future narrower creases as the sole threshold. This is a normative policy ranking, not a visual fit test; the 11.35mm cross-state box proxy favors none of these values. All options still require app information to remain outside the physical crease; none mandates symmetric left/right clearance.
