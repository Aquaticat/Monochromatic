## Purpose and current boundary

Produce the combined provider allocation and cost evidence for the expanded evaluation,
using the approved USD 200 monthly ceiling and Developer baseline.
This note owns normalization work;
it is not an invoice or a declaration that every research lane has been aggregated.
The six-section report must distinguish measured trial intervals from future workload scenarios.

## Independent work items

- Normalize the native CI and GitHub runner included-minute units from current primary wording.
  The platform researcher owns
  [allowance reconciliation](depot-included-allowance-reconciliation.md).
- Retain separate named build,
  native CI and GitHub Actions entitlements;
  do not assume transferable credits or undocumented mixed-OS debits.
- Aggregate solely owned allocations from source-bound lane receipts.
  Use one row per provider job/attempt,
  with run/workflow/job/source identities,
  requested resource shape,
  started/finished timestamps,
  list-rate arithmetic,
  reservation,
  and source-receipt path.
  Deduplicate a job appearing in more than one report.
- Preserve nominal compute proxies separately from free standard public-repository GitHub compute,
  included allowances,
  actual provider charges and unobserved billable VM lifetime.
- Price combined build cache,
  Depot Cache and Registry storage together using the documented unit and averaging period.
  Logical snapshot size,
  compressed manifest bytes and charged storage remain distinct quantities.
- Count passing Tests results using the applicable included allowance and result rate;
  retain failed/errored/skipped billing treatment from the primary source.
- Construct the proposed task graph from actual owners and prerequisites.
  Shared producer work appears once;
  parallel branches contribute through their critical path,
  not the sum of their elapsed durations.
- Keep current-source functional profiles distinct from unchanged-input timing cohorts.
  Preserve run-to-run spread before assigning a speed ratio.
- Calculate waiting value using the retained CAD input and dated FX observation.
  Overlapping unfinished intervals count once.
- Produce explicit monthly scenarios with event counts and scope assumptions.
  Historical Scorecard-heavy event volume cannot stand in for the expanded task graph.

## Publication controls

Every allocation row needs a retained source and a stable deduplication key.
Every scenario must state whether included-allowance arithmetic is documented or conditional.
A conservative reservation is not relabeled as an observed charge.
The native-CI-only comparison in the historical hybrid model does not establish all-product dominance.
The finished model feeds the expanded evaluation;
it does not silently replace historical trial inputs or authorize a subscription change.
