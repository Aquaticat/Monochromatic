## Representation change

Replace only the one symbolic `supplied_operation` token in each hypothesis with a canonical phrase rendered from
code-established facts.
For example:

- Existing-cache-content removal at the parsed target.
- Local reading of file contents at the structured read-tool path.
- Sending file contents from the parsed source to the parsed external destination.

Resources and destinations use JSON-quoted literals within the hypothesis text,
then normal JSON encoding at each request boundary.
The operation is not reconstructed by a model from raw Bash.
The query,
claim definition,
complete policy,
model,
and remaining flags stay unchanged.
Local controls compare those exact unchanged fields and adversarial quote,
backslash,
newline,
and traversal-shaped text preservation.

This tests whether concrete operation wording adds information.
It is not a claim that this representation will improve accuracy or calibration.
No previous probability head is applied to changed features.
