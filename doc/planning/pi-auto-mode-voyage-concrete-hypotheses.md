code-established facts.
For example:

- Existing-cache-content removal at the parsed target.
- Local reading of file contents at the structured read-tool path.
- Sending file contents from the parsed source to the parsed external destination.

Resources and destinations use JSON-quoted literals within the hypothesis text,
then normal JSON encoding at each request boundary.

claim definition,

and remaining flags stay unchanged.

This tests whether concrete operation wording adds information.
