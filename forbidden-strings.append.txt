# forbidden-strings shared appendix (checked into version control).
# Non-sensitive deny-list rules that apply to every clone of this repo.
# Add literal substrings or /PATTERN/FLAGS regex rules below; one per line.
# This file is concatenated onto forbidden-strings.local.example.txt and
# forbidden-strings.append.local.txt by file-enforcer to produce the runtime
# forbidden-strings.local.txt. Keep sensitive rules (codenames, customer
# names, partner identifiers, politically-charged literals) out of this file;
# put those in the gitignored forbidden-strings.append.local.txt instead.

# Rule-label regex prefix used below:
# ^[ \t]*(?:-[ \t]+|[0-9]+\.[ \t]+)?
# Matches AGENTS.md shortcode labels at line start, after optional indentation,
# optional dash-list marker, or optional numbered-dot list marker.
# Uses [0-9] deliberately because AGENTS.md numbering is ASCII Markdown syntax, not Unicode digits.
# Does not match generic Markdown markers like `*`, `+`, or `1)` because AGENTS.md uses `-` and `1.` forms.
